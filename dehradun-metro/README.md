# 🚇 Dehradun Metro - Web Interface

## Visual Metro Route Mapper

Modern web-based UI for the Dehradun Metro project with:
- 🗺️ Interactive visual metro map
- 🎯 Station selection dropdowns
- ⚡ BFS & Dijkstra algorithms
- 💰 Automatic fare calculation
- 📊 Visual route display

## How to Run

### Simply open in browser:
```
Right-click on index.html → Open with → Browser
```

Or double-click `index.html`

### Files:
- `index.html` - Main HTML page
- `style.css` - Modern styling
- `data.js` - Station & route data
- `algorithms.js` - BFS & Dijkstra
- `app.js` - Main application logic

## Features

1. **Visual Metro Map**
   - Interactive station markers
   - Colored metro lines (Yellow, Blue, Red)
   - Zoom controls

2. **Smart Route Finding**
   - Select source & destination
   - Choose algorithm:
     - Shortest Distance (Dijkstra)
     - Minimum Stops (BFS)

3. **Journey Details**
   - Complete route path
   - Line change indicators
   - Travel time & distance

4. **Fare Calculator**
   - Base fare + Distance charge
   - Interchange fees
   - Complete breakdown

## No Installation Required!

Just open `index.html` in any modern browser (Chrome, Firefox, Edge).

All code runs in the browser - no server needed! ✨
